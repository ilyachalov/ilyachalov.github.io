Вышло что-то вроде очень простого текстового редактора, которому далеко даже до «Блокнота», входящего в операционную систему Windows.

Символы появляются в окне сразу после нажатия соответствующих клавиш на клавиатуре. Реализовано удаление предыдущего символа или символов нажатием на клавишу Backspace на клавиатуре. Реализован переход на следующую строку нажатием клавиши Enter. Реализован автоматический переход на следующую строку по словам при достижении правой границы клиентской области окна. Для этого я использовал одну из встроенных возможностей функции [DrawText](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-drawtext).

Можно было бы еще добавить возможность изменения шрифта, но решил этого пока не делать, а обойтись шрифтом по умолчанию.

Текст выводится в клиентскую область окна с внутренним отступом в 10 пикселей, этот размер настроен в программе и его можно в случае необходимости поменять.

## Исходный код программы

В качестве основы взята заготовка из [предыдущего поста]({% post_url 2026-10-18-cpp-gui-windows-winapi %}).

Для хранения символов использую объект типа `std::wstring`, поэтому в начале программы добавил включение соответствующего заголовочного файла:

```cpp
#include <string>    // для std::wstring
```

В инструкции создания класса окна пришлось внести дополнительную инструкцию для корректной перерисовки окна при изменении его размеров:

```cpp
    wc.style = CS_HREDRAW | CS_VREDRAW;
```

Основные изменения внесены в код функции `WndProc`:

```cpp
// функция окна для обработки сообщений
LRESULT CALLBACK WndProc(HWND hWnd, UINT uMsg, WPARAM wParam, LPARAM lParam)
{
    static std::wstring text{ L"" };

    switch (uMsg)
    {
        case WM_CHAR:
            {
                wchar_t ch{ static_cast<wchar_t>(wParam) };
                if (ch == L'\b')      // клавиша Backspace
                {
                    if (!text.empty()) text.pop_back();
                }
                else if (ch == L'\r') // клавиша Enter
                {
                    text += L'\n';
                }
                else if (ch > 31)     // кроме управляющих символов
                {
                    text += ch;
                }
                InvalidateRect(hWnd, NULL, TRUE);
            }
            break;
        case WM_PAINT:
            {
                PAINTSTRUCT ps;
                HDC hdc{ BeginPaint(hWnd, &ps) };

                RECT rect;
                GetClientRect(hWnd, &rect);
                rect.left += 10;   // внутренние отступы в пикселях
                rect.top += 10;    // от края клиентской области окна
                rect.right -= 10;
                rect.bottom -= 10;
                SetBkMode(hdc, TRANSPARENT); // прозрачный фон для символов
                DrawText(hdc, text.c_str(), -1, &rect, DT_WORDBREAK);

                EndPaint(hWnd, &ps);
            }
            break;
        case WM_DESTROY:
            PostQuitMessage(0);
            break;
        default:
            return DefWindowProc(hWnd, uMsg, wParam, lParam);
    }

    return 0;
}
```

При получении окном от операционной системы сообщения `WM_CHAR` (это сообщение генерируется нажатием любой клавиши на клавиатуре) изменяем соответствующим образом строку, хранящуюся в объекте с названием `text`. После этого вызовом функции `InvalidateRect` отправляем окну сообщение `WM_PAINT` для перерисовки клиентской области окна. (На самом деле, эту отправку выполняет не сама функция `InvalidateRect` напрямую, но она является инициатором этой отправки.)

При получении окном сообщения `WM_PAINT` с помощью функции `DrawText` рисуем текст из объекта `text` в клиентской области окна, отступив от краев клиентской области внутрь на 10 пикселей. По умолчанию фон символов не совпадает с фоновым цветом клиентской области, установленным мною при создании класса окна. Поэтому делаем фон рисуемых символов прозрачным с помощью функции `SetBkMode`.

Переменную (объект) `text` пришлось сделать статической `static`, чтобы хранящийся в ней текст не терялся между вызовами функции `WndProc`.
